# 河南德航建设工程有限公司 · 官网

深蓝 × 鎏金配色，沉稳大气、专业高端的企业官网，采用纯静态实现（HTML + CSS + 原生 JS），**无需任何构建工具或服务器**，双击 `index.html` 即可打开浏览。

## 使用方式

1. 直接双击 `index.html` 在浏览器中预览（推荐 Chrome / Edge）。
2. 部署时将整个文件夹上传至服务器或静态托管平台（如云虚拟主机、OSS、GitHub Pages 等）即可。

## 目录结构

```

```

2. **留言表单**：目前为纯前端演示，正式上线需接入后端接口或第三方表单服务

## 响应式设计

- 桌面端（>1100px）：四列布局
- 平板端（≤992px）：导航收起为汉堡菜单，三列/两列布局
- 手机端（≤768px）：单列流式布局，表单单列，表格横向滚动

## 技术说明

- 无任何第三方依赖（无 CDN、无字体外链），国内网络环境加载无忧
- 图片均已设置懒加载（`loading="lazy"`），首屏优先加载
- 已适配 `prefers-reduced-motion`（减少动态效果偏好）
- 视频体积较大（约 27MB），正式上线建议压缩后再部署
